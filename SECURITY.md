# Security Policy

## Supported Versions

We currently provide security updates for the latest release of patchsplit.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅         |
| Older releases | ❌         |

Older versions may not receive security fixes. Please update to the latest release before reporting an issue that may already be fixed.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in patchsplit, please report it privately.

**Please do not open a public GitHub issue for an undisclosed security vulnerability.**

You can report security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/zitzhen/patchsplit/security/advisories/new), if available.

Alternatively, contact the maintainer privately through GitHub.

When reporting a vulnerability, please include:

* A description of the vulnerability.
* Steps to reproduce the issue.
* The affected version.
* The expected and actual behavior.
* Any relevant logs, proof of concept, or other details.

Please avoid including sensitive personal information in your report.

## Disclosure

We will investigate reported vulnerabilities and work with the reporter to understand and address the issue.

Please allow time for a fix to be developed and released before publicly disclosing the vulnerability.

We appreciate responsible disclosure and the effort of security researchers who help improve patchsplit.

## Security Updates

Security fixes will be included in a future release when appropriate.

Release notes may include security-related changes and affected versions.

Thank you for helping keep patchsplit secure!
